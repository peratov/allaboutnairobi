Most rent in Nairobi is paid by bank transfer or [[M-Pesa]], and the
transaction message is useful evidence. It does not say what the money was
*for*. A receipt that names the unit, the period and whether it was rent or a
deposit does, and that is what matters when you ask for the deposit back.

Ask for one whenever you pay a deposit, and whenever you pay cash.

## The template

```
RENT / DEPOSIT RECEIPT                         No. ________

Date: ______________________

Received from (tenant):   ___________________________________
ID / passport number:     ___________________________________
Phone:                    ___________________________________

Paid to (landlord / agent): ___________________________________
ID number or company:       ___________________________________
KRA PIN:                    ___________________________________
Phone:                      ___________________________________

Property:  House / unit no. ________  Building / court ____________
           Road ______________________  Area ______________________

Amount:    KES ______________ (in words: ___________________________)

This payment is for (tick one):
  [ ] Rent for the period ______________ to ______________
  [ ] Security deposit (refundable)
  [ ] Water deposit (refundable)
  [ ] Electricity deposit (refundable)
  [ ] Service charge for ______________
  [ ] Other: ______________________________

Paid by:   [ ] Bank transfer, ref ______________
           [ ] M-Pesa, code ______________
           [ ] Cash

Balance outstanding, if any: KES ______________

Received by (signature): ___________________   Name: _______________
Tenant (signature):      ___________________
```

## Why each part is there

- **The unit and building.** Receipts that just say "rent" can be argued to
  cover a different unit or a different tenant.
- **The period.** "Rent for March" is clearer than a date, and stops a payment
  being reallocated to arrears.
- **Deposit or rent, ticked.** A deposit is refundable; rent is not. Mixing
  them up is how deposits disappear.
- **The M-Pesa code or bank reference.** Ties the receipt to the actual
  transaction.

## Keep it safe

Photograph the receipt as soon as you get it and save it with the lease and
the move-in photos. See [Finding housing](/guides/finding-housing#moving-out-and-getting-the-deposit-back).
